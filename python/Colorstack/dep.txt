## Windows Compatibility Notes / Windows Compatibiliteitsnotities / Notas de Compatibilidad Windows

### ✅ Fully Compatible / Volledig Compatibel / Totalmente Compatible
- PyQt6 (GUI framework)
- opencv-python (computer vision)
- numpy (numerical computing)
- scikit-learn (KMeans clustering)
- svgwrite (SVG generation)
- trimesh (3D mesh operations)
- svgpathtools (SVG path parsing)
- pillow (image processing)

### ⚠️ Potential Issues / Mogelijke Problemen / Posibles Problemas

**1. PyQt6.QtSvg (SVG Rasterization)**
- Used in `_rasterize_svg()` function for SVG preview
- Requires Qt SVG plugin (`qsvg.dll`)
- **Fix**: Included in standard PyQt6 Windows wheels. If missing, install via:
  ```cmd
  pip install --upgrade PyQt6
  ```
  Or copy `qsvg.dll` from `PyQt6/Qt6/plugins/iconengines/` to app directory.

**2. shapely (Geometry Operations)**
- Requires GEOS C library
- **Fix**: Included in modern shapely wheels (>=2.0). If `GEOS` error occurs:
  ```cmd
  pip install --upgrade shapely
  ```
  Or install GEOS separately: `conda install -c conda-forge geos`

**3. trimesh (3D Mesh Operations)**
- Pure Python with optional dependencies (pyembree, rtree, etc.)
- Core functionality works without optional deps
- **Fix**: For better performance, install optional deps:
  ```cmd
  pip install pyembree rtree
  ```

**4. File Paths**
- Uses `pathlib.Path` for cross-platform paths ✅
- Uses `os.fspath()` for compatibility ✅

**4. SVG Rasterization Fallback**
- If `PyQt6.QtSvg` unavailable, SVG preview falls back gracefully
- App continues to work without SVG rasterization
